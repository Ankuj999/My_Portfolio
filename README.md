# 💼 Ankuj Saha – Data Science Portfolio

Welcome to my personal data science portfolio built using **Streamlit**. This interactive web app showcases my **projects**, **certifications**, **internships**, and **education** in a clean and accessible format.

🔗 **Live Demo**: [View Portfolio](https://ankuj-portfolio.onrender.com/)

---

## 📌 About

This portfolio is designed to highlight my skills in **Data Analytics**, **Machine Learning**, and **Visualization**. It includes detailed sections for:

- Projects with dashboards and deployment links
- Internship experiences and certifications
- Education background
- Contact and social profiles (LinkedIn, GitHub)

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **HTML/CSS** (via Streamlit Markdown)
- **Power BI** (Embedded links)
- **Render** (for deployment)
